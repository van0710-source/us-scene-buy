# 合规与拒答边界（初稿）

> 非律师意见；上线前需按美国联邦/州与联盟协议再核。

## 联盟与广告

- 显著披露 affiliate 关系（FTC 精神：clear and conspicuous）
- 不伪造测评、不伪造「实验室结论」
- 价格/库存可能变化；标明信息时效
- 禁止误导性「最低价保证」

## 化学品 / 排水类（MVP 相关）

- 强调按标签使用；警告混用风险（尤其酸碱/含氯产品）
- 不承诺「百分百疏通」「永不复发」
- 老旧管道、化粪池、租房限制等场景：倾向保守建议，必要时建议专业管道工
- 不把产品说成医疗/消毒防疫方案（除非有合法依据且非本阶段重点）

## 生成内容纪律

- 利益点必须挂在可核对事实上（厂商标称 / 公开规格 / 可引用来源类型）
- 事实撑不住时降级措辞（「按标称…」「评价里常见…」），禁止脑补时长与效果
- 保留「不买 / 先物理疏通 / 先打电话」路径

## 隐私（决策资产采集时）

- 最小化：会话级约束与点击为主
- 明确告知用途；支持删除
- 不做全家健康档案；少强迫登录
- 注意州隐私法（如加州）趋势

## 明确不做的表述

- 诊断疾病、用药建议
- 未披露的软广口吻冒充独立测评
