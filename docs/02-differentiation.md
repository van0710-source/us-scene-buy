# 差异化

## 定位（一句话）

面向某一品类的 **约束式购物决策助手**：先问清限制，再给出唯一主推荐 + 明确放弃项，利益点讲「对你意味着什么」，并用可核对参数作锚；附联盟链接与披露。

## 相对竞品

| 相对谁 | 我们的差异 | 不拼 |
|--------|------------|------|
| ChatGPT 等通用 AI | 品类流程固定、结构化、链接可追踪 | 知识广度 |
| Amazon Rufus 等站内 AI | 以用户约束为中心；可建议不买/等待 | 目录与物流 |
| Wirecutter 等测评 | 个性化、即时权衡 | 实验室权威 |
| 优惠/比价插件 | 先解决「买哪个」 | 券库 |

## 核心公式（必须遵守）

```text
用户约束 → 场景利益点（触达） → 参数/声称锚（敢下单） → 联盟链接
```

示例（保温杯逻辑，本项目类推到排水场景）：

- 弱：大容量、18 小时保温  
- 强：按你说的 4 小时会议，散会时大概率还有冰饮——厂商标称冷藏保温约 18 小时  

## 输出结构（建议验收标准）

每次决策输出尽量包含：

1. **1 个主推荐**（对准已确认约束）
2. **最多 2 个备选**（说明适用何种不同约束）
3. **不买 / 等待 / 先尝试非购买方案**（若适用）
4. 每条关键利益点映射到用户原话约束 + 产品事实依据类型
5. 联盟披露与信息时效提示

## 不算差异化

- 「我们用了更新模型」
- 纯文风更好看的广告句（无约束、无依据）
- 链接更多、全网比价
