## 当前主线：扫地机器人替换耗材兼容

```text
完整品牌+型号
  → 厂商兼容表确认耗材家族
  → 明确相近型号错配
  → Amazon 精确型号购物入口
```

| 层 | 第一轮 |
|---|---|
| 品牌 | Roborock + Dreame |
| 型号 | 10 个有美国厂商来源的主流型号 |
| 耗材 | 尘袋、滤网、拖布、主刷/边刷 |
| 产品形态 | 单字段型号选择器 + 每型号静态兼容页 |
| 验证 | GSC 精确型号词 → Umami 页面/事件 → Associates Clicks/Orders |

**为什么改刀：** 替换耗材是计划性购买；型号本身承载约束，用户无需在堵塞应急时回答五题。厂商公开兼容资料可替代不可得的真人访谈，但不能替代真实点击与订单验证。

**禁止扩张：** 首轮未过门闩前，不增第三品牌、不做电池/维修、不把空气或硬地探针扩成第二套完整站。

## 以下为 2026-07 厨房排水历史方案

## 三种原型

| 原型 | 特征 | 角色 |
|------|------|------|
| ① 周期耗材 + 有得选 | 用完再买，规格/配方有门道 | 基本盘（复购） |
| ② 耐用/半耐用 + 决策重 | 几年一买，选错疼，约束多 | 基本盘（客单） |
| ③ 急用型问题购买 | 平时无感，出事才搜 | 获客侧翼（SEO/解决问题） |

## 选类硬性门槛

1. 美国联盟可做（可追踪链接、类目不敏感）
2. 决策有分叉（≥3 个真实约束会改变推荐）
3. 能场景利益化
4. 合规可控
5. 纯跳转，不碰货与资金

## 优先排序加分

- 决策难 +（高复购或高需求频）
- 更换成本低、愿试新推荐 = **加分，不单独成立**
- ③ 可做，但不用「高复购」标准要求它；成功看获客成本与能否导到 ①②

## MVP 主线（已定）

**住宅：厨房排水 / 异味 → 养护耗材 →（后置）清洁或厨余相关设备**

| 阶段 | 切片 | 原型 |
|------|------|------|
| 前 3 个月 | 厨房水槽堵塞、排水异味应急选品 | ③ |
| 同步轻量 | 管道养护、酶制剂/定期维护等耗材 | ① |
| 站稳后 | 垃圾处理、吸尘器/洗地机、净化器等（按场景延伸） | ② |
