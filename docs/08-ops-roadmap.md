# 整体操作路径

更新日期：2026-07-17

操作总图：策略规格 → 无佣金软测 → 申请联盟 → 带追踪硬测 → SEO 获客 → ③→① 养护 → 对内打点。  
产品规格见 [`07-mvp-kitchen-drain.md`](07-mvp-kitchen-drain.md)；工作勾选见 [`06-next-steps.md`](06-next-steps.md)。

## 已锁定运营约束

1. **零外部投放预算**：形成项目收入前不做付费投放；之后投放也只能用项目收入，不追加外部资金。
2. **运营者身份**：中国开发者（非美国税务居民）对接美国联盟与收款。
3. 商业模式仍为纯联盟；不经手货款；MVP 切口不变。

---

## 瓶颈结论（先读）

| 约束 | 是否「做不成」 | 实际影响 |
|------|----------------|----------|
| 无收入前不投放、投放只吃项目收入 | **否**（与方案乙「少投广告」一致） | 冷启动只能靠 SEO/自然传播；时间是主成本；后期也很难靠广告放大 |
| 中国身份 + 美国联盟税务/收款 | **否**（常见可走通） | Phase2 起有流程摩擦（W-8BEN、预提税、跨境收款）；不挡 Phase0–1 |

真正瓶颈是：**薄佣金 × 无投放 × 英语 SEO 冷启动** 的时间与单位经济——不是「不能注册联盟」或「不能开发产品」。

### 资金约束

不会卡死实施，会卡死快速放量。

- 厨房排水客单常几十美元量级，Home 佣金常见约 1%～4%；再扣退货、Net 30～60、可能的预提税，单次净收入往往很小。
- 「用项目收入再投放」在早期 ≈ **长期以有机流量为主**；付费难成增长引擎。
- 必须做高：约束完成率、主推点击、③→① 复访；允许「不买」会压转化——体验正确，收入更慢。

### 税务与收款（中国开发者）

> 非税务/法律意见；开户与报税前咨询跨境税务顾问或会计师。

| 阶段 | 做法 |
|------|------|
| Phase0–1（未赚钱） | 无需美国公司/EIN；无 tag 软测即可 |
| Phase2 开联盟 | 个人填 **W-8BEN**（非 W-9）；实体用 W-8BEN-E；站点须有实质内容 + FTC 披露 |
| 预提 | 信息无效时，美方可能对非美 Associates 预提最高约 30%；协定能否降低须专业确认，本文不默认能降很低 |
| 收款 | 美国站常不支持大陆卡直接 deposit；实务多用第三方跨境收款 / 礼品卡等 |
| 中国侧 | 境外所得可能需申报个税；与美方预提抵免问会计师 |
| 后期可选 | 港/美主体仅在收入稳定后考虑，**非 MVP 前置** |

### 壁垒清单（按杀伤力）

| 壁垒 | 级别 | 缓解 |
|------|------|------|
| SEO 冷启动时间 | 高 | 极窄词；先 P1 选题；接受 3～6 个月验证窗 |
| 薄佣金 × 低客单 | 高 | 强化 ① 复购；② 设备后置 |
| Associates 审核 / 合格期 | 中高 | 先上实质页再申；规则以当时后台为准 |
| 英语内容与本地信任 | 中 | 靠约束式流程 + 可核对事实锚，不拼实验室权威 |
| 归因损耗（App/Cookie） | 中 | 早期 KPI 看点击与完成率，佣金滞后参考 |
| 化学品合规 | 中 | 见 `07` 拒答清单 |
| 免费替代（通用 AI / 论坛） | 中 | ≤5 题 + 主推 1 + 允许不买 + 可点链接 |
| 跨境税务收款 | 启动中低 | W-8BEN + 收款通道 |
| 无额外投放预算 | 战略中低 | 默认「有机增长实验」 |

**改模式信号**：公开页 + 持续 SEO ≥4～6 个月仍几乎无意向访问；或有访问但访谈证明决策输出无用 → 换切口/加强 ①，**不要**先加投放或先注册美国公司。

## 阶段总览

```text
Phase0 策略与P0规格（已完成）
   → Phase1 无佣金软测
   → Phase2 申请 Amazon Associates（有实质公开页后）
         ├─ 获批 → Phase3 带追踪硬测
         └─ 未获批 → 加厚内容，留在 Phase1 复申
   → Phase4 SEO 获客（默认零付费）
   → Phase5 ③→① 养护闭环
   → Phase6 对内打点（可与 3～5 并行）
```

读法：先证明「决策流程有人愿意走完并点击」→ 再开联盟 → 再靠 SEO 获客 → 再导养护复购。

## Phase 0 — 策略与产品规格（已完成）

- 交付：`00`～`07`
- 不需要联盟账号；链接可用 `?tag=YOURTAG` 占位

## Phase 1 — 无佣金软测（原型已有，待真人测）

**目标**：验证问卷 → 主推 1 → 点击/不买，不依赖佣金。

| 项 | 做法 |
|----|------|
| 产物 | [`prototype/kitchen-drain.html`](../prototype/kitchen-drain.html)（Q1–Q5、路由、输出、养护模块、样例 A–D） |
| 链接 | 普通 Amazon 页（无 Associates tag） |
| 披露 | 页内已写推广关系/决策信息提示（软测说明无 tag） |
| 对象 | 5～15 人（租房/厨槽问题场景） |
| 看什么 | 约束完成率、主推是否说得通、点击意愿、拒答是否触发 |
| 不做 | 付费投放、多联盟、设备② |

**通过**：多数人答完 ≤5 题；不像硬推销；有人点主推或明确「先不买」。

## Phase 2 — 申请联盟（软测接近跑通 + 有公开页）

**站点产物（本地已齐）**：[`site/`](../site/) — 首页、问卷、T02/T03/T04 指南、养护页；页脚含披露。

**何时申请**：`site/` **已部署到可公开访问的 HTTPS URL**，且内容可点（非空白站）。

**与谁**：本阶段只做 **Amazon Associates（美国）**；Impact/CJ/Walmart 等暂缓。

**清单**：

1. W-8BEN（个人）、跨境收款通道、站点 URL、说明「厨房排水选品助手」
2. 申请；全站 FTC 式披露（`site` 页脚已有初稿）
3. 获批后：在 `site/assets/quiz.js` 为 ASIN 链接加真实 `tag`；核对化学品类目是否可推
4. 佣金作滞后参考；不规划付费投放直至有可复用佣金结余

**未获批时**：加厚 `site/guides/`（T05/T01 等）后复申。

## Phase 3 — 带追踪硬测（获批后）

- 链接：`https://www.amazon.com/dp/{ASIN}?tag=你的tag`
- 再跑样例 A/B/C/D；看主推点击、出站、披露、报表点击
- **通过**：追踪点击可见；无合规红灯

## Phase 4 — SEO 获客（③）

- 首批成页：`site/guides/`（T02 / T04 / T03 + 养护）
- **默认零付费获客**
- 指标：有机访问、问卷开始率、主推点击
- 续写顺序仍见 `09` §1.4（T05 → T01 → …）

## Phase 5 — ③→① 养护

- 对应 `06` P1-6：急用输出末尾「下次别等到堵死」→ 维护耗材
- ② 设备仍后置

## Phase 6 — 对内打点

- 对应 `06` P2-7 + `05`：约束、主推/备选/不买；对外不谈数据护城河

## 建议时间顺序

```text
现在     Phase1 软测（约 1～2 周）
        ├─ 可并行：P1 SEO 选题地图
        └─ 有公开页后提交 Associates
获批后   Phase3 硬测（数天～1 周）
        → Phase4 按选题连续发文
        → Phase5 强化养护 CTA
全程     Phase6 最小打点；周更问题与利益模板
```

联盟不是第一步；赚钱验证在获批 + 硬测之后。
