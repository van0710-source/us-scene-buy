# 决策资产（对内）

## 原则

- **对外**：只做用户体验；不提大平台、大数据、护城河。
- **对内**：沉淀可回流的品类决策资产，作为中长期区隔。

## 纯联盟下可采集的信号

| 信号 | 优先级 |
|------|--------|
| 用户约束（场景、预算、忌点、住房/管道情况等） | 高 |
| 主推 / 备选 / 「先不买」点击 | 高 |
| 利益点展开与停留 | 中高 |
| 联盟佣金回传 | 中低（延迟、噪声） |
| 是否最终满意/退货 | 低（通常拿不到） |

## 推荐形态（不是「宣传数据库」）

1. **结构化库**：维度字典、场景、约束、产品事实、利益模板、事件日志  
2. **决策关系层**：`约束 → 权衡 → 利益点 → 产品属性` + 权重  
3. **趋势层（后期）**：维度热度、新兴忌点  

先规则+计数，再模型。向量检索可后加。

## 最小闭环（验证用）

```text
输出前：≤5 个结构化约束
输出中：利益点 + 参数锚，可追踪
输出后：点击主推/备选/不买 + 可选 1 题「最打动点」
每周：调问题优先级与利益模板
```

## 主指标（早期）

- 约束完成率
- 主推链接点击率
- 复访 / ③→① 路径转化（同会话或回访）
- 佣金仅作滞后参考
