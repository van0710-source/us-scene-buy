# 商业模式与现金流

## 角色

| 角色 | 职责 |
|------|------|
| 我们 | AI 购物决策产品 + 联盟推广者（Publisher） |
| 零售商（如 Amazon） | 卖家、收款、发货、售后 |
| 联盟平台 | 追踪成交、按类目比例结算佣金 |
| 用户 | 在零售商处完成支付与收货 |

## 资金流（商品侧）— 我们不碰货款

```text
用户 --点击追踪链接--> 零售商收款并履约
                         |
                         +--> 有效订单过退货窗口后计入可付佣金
                         +--> 平台 Net 30~60 左右向我们打佣金
                         +--> 退货/取消会冲减佣金
```

## 资金流（产品侧，可选）

- 可另收软件订阅费（与货款分离）；早期也可只靠佣金。
- **禁止**：代用户收款买货再转付；担保交易/资金池。

## 美国联盟现实

- 选品/链接：Amazon Associates 等相对「一键」，但是返点不是代发。
- 代发（Zendrop/CJ 等）存在，但是自营 MoR，**本项目不做**。
- Home / Home Improvement 等佣金常见约 3% 档：靠 **低获客成本（③）+ 复购（①）+ 客单（②）** 组合，不赌超高佣金类目。

## 交椅一句话

> AI 决策工具 + 美国联盟追踪链接（平台结算返点）；不经手商品货款。
