Why old pipes change the default

  • Why caution: Aggressive chemistry is a worse default when pipes may already be thin, scaled, or joint-sensitive. We won’t promise “safe on all old iron.”
  • Better first moves: Cup-style sink plunger; plastic drain snake if the opening is large enough; stop if multiple fixtures back up.
  • Slow grease (still flowing): Habits + enzyme/maintenance labels beat panic gels for many kitchens — read the bottle you buy.
  • Fully stuck + old pipes: Prefer plumber over stacking openers, especially if a chemical already went down.
Never mix drain chemicals. Already poured something? Don’t add a second product — follow that label or call a pro.
